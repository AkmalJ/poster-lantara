# LANTARA — The Town Inside the Lantern

A travel poster for a place that does not exist: a harbour town living
inside a colossal brass lantern afloat on a dusk sea. `main.py` sets the
poster type and frame over the painted artwork (`art.jpg`) and writes
`/output/entry.png`, 1024x1024, inside the size gate.

Run: `python3 main.py`
